# Smallway Desktop MCP — brand and attribution

Product: Smallway Desktop MCP
Repository: https://github.com/0800happy/smallway-desktop-mcp
Maintainer: Smallway
Upstream: DeskMCP by edmen12 (https://github.com/edmen12/deskmcp), Apache-2.0.
This is an independent fork, not an official DeskMCP product or release.

Compatibility: existing DeskMCP.exe, internal DesktopMCP data roots, Gateway ports,
Startup shortcut identity, tool names, and internal process names are deliberately retained
to preserve installed settings and safe upgrades. They are NOT displayed as the new brand.
Do not run two versions simultaneously with the same data root.
