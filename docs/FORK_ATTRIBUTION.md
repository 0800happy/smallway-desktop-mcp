# Fork attribution and compatibility

Smallway Desktop MCP is based on DeskMCP by edmen12 (https://github.com/edmen12/deskmcp) under Apache License 2.0.
The original author does not endorse or maintain this fork.

Legacy internal binary, data folder, registry, startup shortcut, local control and
MCP tool identifiers are retained intentionally to preserve existing installed
Tunnel, Workspace and permission settings. Visible product branding is Smallway Desktop MCP.

Upgrading requires a backup of the existing DeskMCP data and installation. Do not
run the original and fork concurrently with shared data. The new release updater
points to the Smallway-owned repository, not to upstream.
